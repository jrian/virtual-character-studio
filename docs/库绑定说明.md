# 三项库绑定说明

本项目将库的公开元数据和选择器绑定，用户选择服装后，内容写入角色正文、一致性提示词、Markdown 导出及保存档案。

| 项目 | 已入库数据 | 页面入口 |
| --- | --- | --- |
| Open Pose & Costume | 2727条服装元数据，含1407条写实与1320条动漫 | 外貌与造型 → 从已绑定服装库选择 → 来源筛选 |
| AI Library | 1407条写实服装来源映射，与前项写实条目去重 | 同上，选择AI Library来源 |
| Fashionpedia | 46类服装或部件、294项属性 | 外貌与造型 → 用Fashionpedia细化服装 |

## 仓库文件

- `data/bound-libraries.json`：完整绑定快照，每件服装有规范ID、分类、类型、关键词、源站链接、来源成员和来源编号。
- `data/bound-libraries.js`：同数据的浏览器脚本格式；避免 file:// 下 fetch JSON 的限制。
- `data/fashionpedia-taxonomy.json`：官方分类属性结构快照。
- `data/library-manifest.json`：固定上游版本、文件路径、日期和存储输入的SHA-256摘要。
- `scripts/sync-libraries.mjs`：从固定版本同步元数据，不下载图片。`npm run sync:libraries` 可重建快照；不做自动追随上游更新。
- `library-binding.js`：来源／类型／分类／关键词筛选、选中条目解析与属性选择。
- `THIRD_PARTY_NOTICES.md`：素材、分类本体、字体的出处与许可。

## 去重规则

AI Library 的 1407 条服装记录，其缩略图文件名与 Open Pose & Costume 的写实编号逐项一致。因此规范ID以「realistic:原始编号」保存一次；bindings 中同时保留 OPC 的SPR等编号与AI Library 的C-SP等编号。动漫源使用独立 anime 命名空间。两项目的记录数不能直接相加宣称4134件独立服装。

## 图片边界

本仓库不包含受限的第三方服装图片、缩略图、人物照片或额外授权自建素材。点击条目下的单张原图链接后，由原站显示图片。站点运行不会批量拉取源图。本次放到 GitHub 的库存是可筛选、可绑定到设定的元数据库存。

Fashionpedia 本体／标注为 CC BY4.0；官方条款说明其并不拥有全部原始照片版权，因此本次只使用类别与属性名称。用户输入或选择的服装属性是创作条件，不是本工具对参考图的识别结论。

## 授权与来源边界

- 小型男性库的 [ASSET_LICENSE.md](https://github.com/willie2028/male-ai-reference-library/blob/main/ASSET_LICENSE.md) 将图片标为作者已确认可再分发，并说明不是公有领域，底层模型名称与条款未完全核实。MIT 仅覆盖代码，不能据此把图片标为 MIT 或 CC0；接入前应明确下游使用范围，保留来源、AI 标识及授权依据。
- 男装库的 [ASSETS_LICENSE.md](https://github.com/lwmxiaobei/ai-costume/blob/main/ASSETS_LICENSE.md) 声明自行生成的男装图片为 CC BY-ND 4.0，要求署名并限制公开分享改编版本。其 `upstream/` 历史图片不随该许可重新授权。
- 男装数量来自 [合集说明](https://github.com/lwmxiaobei/ai-costume/blob/main/output/menswear-1200/README.md)，不是把整个仓库所有历史图片计为男装。分类：春 183、夏 217、秋 208、冬 216、内衣 170、派对 41、泳装 46、性感 119。网页入口：[男装服饰集](https://ai-costume-zh.lwmlxy520.workers.dev/)。
- SFHQ-T2I 的 README 陈述作者希望自由使用，但本轮 `LICENSE` 路径返回 404；没有将代码或图片写成已核实 MIT／CC0。

## 未优先采用

- [laxmimerit/male-female-face-dataset](https://github.com/laxmimerit/male-female-face-dataset)：男女分类训练集，README 信息极少，根目录未见图片授权文件；不作为公开参考图库首选。
- [EastAsianMaleFace-3C](https://github.com/L3m1K0uad10/EastAsianMaleFace-3C)：低分辨率裁切、主要供研究教育，来源含公开媒体与名人图片；既不适合完整发型／脸部参考，也不作为角色工坊公开库存优先来源。

下一步建议：先试接小型男性库的数据结构；男装库先核对素材使用方式与托管方案，再决定是否接入图片。此次研究不代表已经完成接入。

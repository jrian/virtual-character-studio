# 角色工坊 v2 验收记录

本次扩展保留分类图库、条件草稿、角色档案、复制及导出；增加参数捏脸、Lovart 本机服务、图片特征确认、版本与预览。

## 已验证

- 14 项 Node 测试：原有规则／图库数据，以及特征锁定、差异合并、来源优先级、条件快照与提示词。
- 9 项 Python 测试：上传限制、请求去重／并发、文字结构、无图片、参考拒绝、超时／确认恢复、服务重启、敏感字段过滤和本机访问边界。
- `gallery-flow.cjs`：真实上游缩略图、选择、分页、放大、异常重试、生成引用、保存及导出。
- `categories-flow.cjs`：分类组合、联动数量、空结果、选择保留和响应式布局。
- `studio-flow.cjs`：真实本机上传；模拟 Lovart 提取／设定／预览、逐项确认、锁定冲突、待确认与超时恢复、版本、旧版导入和 v2 导出；1280、820、390 像素无横向溢出。拦截全部 Lovart 任务，付费调用次数为 0。
- 静态构建采用文件白名单：只发布网页、公开元数据、字体与来源声明；不含 Python 服务、vendor、配置、私有图片或任务。

截图与浏览器结果在本机 `.impeccable/review/`，不发布。预览流程中的纯色测试图片为合成夹具，不能作为实际生图效果或识图质量证据。

## 待用户联网验证

尚未使用真实 AK/SK 调用 Lovart。用户配置本机凭据与项目后，需在网页主动测试图片特征提取、AI 设定和一张预览。Lovart 文字输出格式、具体模型可用性、额度与相貌还原效果以账号实际响应为准；异常结构不会自动采用，参考拒绝与无图不会显示成功。工具偏好不是强制白名单。

## 设计系统

普通功能扩展，保持 DESIGN.md 与 .impeccable/design.json，使用既有森林绿、鼠尾草底、系统正文和控件尺度。检查桌面、手机顶部与参数区、任务区和预览版本对比。未更换视觉系统，未新增生产用位图。

## Lovart 定向导出验收

新增 2 项单元测试，验证实时参数、锁定、有效参考、私有路径排除和目标链接校验；全套前端逻辑测试共 16 项通过。`tests/lovart-export-flow.cjs` 检查实时表单与旧档案区分、手动传图清单、目标项目及其恢复、复制／打开动作、剪贴板拒绝提示、Markdown 下载、任务选择及响应式布局，未提交 Lovart 生成。界面证据为本机 `lovart-export-*.png` 与 `lovart-export-results.json`；沿用既有 DESIGN.md 和 sidecar，无视觉系统替换。

## AI 模型入口验收

新增本机兼容接口配置、保存／测试／清除及文字／识图路由。前端逻辑 16 项、后端 13 项测试通过；新增假 HTTP 模型服务验证连接和设定生成、Bearer 鉴权、响应与密钥隔离，未调用真实收费模型。浏览器 `tests/model-settings-flow.cjs` 验证真实本机配置保存、密钥不回显／不进浏览器存储、主动测试动作、模型来源标签、同域留空保留、清除、直接展开恢复和手机单列布局。实际服务账号、模型权限与识图质量仍须用户配置后验证。截图 `model-settings-*.png` 为本机模拟配置证据；设计复核修复了直接展开不加载配置的问题，最终 disposition ship。

## 独立弹窗验收

三个原生弹窗支持关闭按钮、Esc、遮罩、焦点限制和返回；内部滚动，手机无横向溢出。新 `tests/dialogs-flow.cjs` 验证筛选／输入保留、图库表单归属、生成与导出引用、嵌套放大、校验恢复及首屏图片可见。已有 gallery/categories/model-settings/Lovart-export 浏览器流程已按入口变化适配并通过；Node 16 项通过。全程未提交真实 AI 生成。复核修复了图库首屏被筛选占满的问题，最终单项修复 verdict 为 ship。DESIGN.md 和 sidecar 未变。

根据用户“只是预备入口，后续添加”的确认，提供三平台分组、可选后补链接、用户图片导入和角色用途选择，不接入平台登录或自动抓取。`tests/personal-library-flow.cjs` 在静态与本机后端模式通过，覆盖空分组、来源链接校验、IndexedDB 图片保存／恢复、人物和服装选择及 Lovart 导出引用。未调用真实 AI，未抓取外部收藏夹。图像测试夹具为透明 PNG，不作为实际识图或生成质量证据。用户图像不随构建、GitHub 或角色 JSON 备份发布。

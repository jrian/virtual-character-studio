# 角色工坊 v2 验收记录

本次扩展保留分类图库、条件草稿、角色档案、复制及导出；增加参数捏脸、Lovart 本机服务、图片特征确认、版本与预览。

## 已验证

- 14 项 Node 测试：原有规则／图库数据，以及特征锁定、差异合并、来源优先级、条件快照与提示词。
- 9 项 Python 测试：上传限制、请求去重／并发、文字结构、无图片、参考拒绝、超时／确认恢复、服务重启、敏感字段过滤和本机访问边界。
- `gallery-flow.cjs`：真实上游缩略图、选择、分页、放大、异常重试、生成引用、保存及导出。
- `categories-flow.cjs`：分类组合、联动数量、空结果、选择保留和响应式布局。
- `studio-flow.cjs`：真实本机上传；模拟 Lovart 提取／设定／预览、逐项确认、锁定冲突、待确认与超时恢复、版本、旧版导入和 v2 导出；1280、820、390 像素无横向溢出。拦截全部 Lovart 任务，付费调用次数为 0。
- 静态构建采用文件白名单：只发布网页、公开元数据、字体与来源声明；不含 Python 服务、vendor、配置、私有图片或任务。

截图与浏览器结果在本机 `.impeccable/review/`，不发布。预览流程中的纯色测试图片为合成夹具，不能作为实际生图效果或识图质量证据。

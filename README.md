# 角色工坊

一个无需密钥的中文静态网页工具。选择身份、外貌、服装方向、性格和世界背景，组合生成可保存、复制和导出的虚拟人角色设定，覆盖虚拟博主、小说、游戏场景。

## 使用

直接打开 `index.html` 即可使用；也可执行 `npm start`，访问 http://localhost:4173 。无需安装依赖。

1. 选择预设或修改角色条件。
2. 在「外貌与造型」选择发长和具体发型，可选关联原站参考记录。
3. 选择 1–3 项性格，补充语气与约束。
4. 生成设定，复制、下载 Markdown 或保存到「我的档案」。

修改条件会标明现有档案尚未更新；点击生成后使用新条件。预设和随机灵感只修改条件，不自动覆盖生成结果。

## 数据和边界

- **本地规则组合，不调用大语言模型或图像生成服务。** 补充要求原样列入独立章节；不会对自由文本作语义推理。
- 姓名、习惯、弱点等细节随生成变化。相同条件可换一版，但不承诺每次全部段落不同。
- 人物参考来源： https://ai-portrait-gallery.pages.dev/ 。2026-11-13 提取 1,499 条公开记录（893 面部、606 造型）；四种发长与50种非空发型标签。中文为本项目编辑翻译。
- 只保存元数据与链接，不存储或代理原站图片。外观记录不用于推断年龄、性格、国籍等人物信息。
- 「参考资源」区分已绑定的服装元数据与其他调研候选，未导入图片，不代表已获素材再分发许可。见 [来源信息](docs/来源信息.md) 和 [GitHub资源调研](docs/GitHub资源调研.md)。
- 条件草稿与保存档案留在当前浏览器，不上传、不跨设备同步。可导出/导入 JSON 备份；清除浏览器数据会删除本机档案。保存失败会提示下载备份。

## 验证与构建

```sh
npm test
npm run build
```

`dist/` 只包含网页运行文件，不含开发文档、设计契约或凭据。所有资源使用相对路径，适配 GitHub Pages 项目子路径。

GitHub Actions 在 main 更新时运行生成逻辑测试，构建并部署 Pages。首次部署需在仓库 Pages 设置选择 GitHub Actions。

项目上下文与设计文档应一同提交：PRODUCT.md、DESIGN.md、.impeccable/surfaces/ 与 .impeccable/design.json。浏览器测试证据保留在本机 .impeccable/review/，不随站点发布。

## 三项库绑定

已经绑定 **Open Pose & Costume、AI Library、Fashionpedia**，在「外貌与造型」展开服装库选择。

- Open Pose & Costume：2,727 条上游服装元数据（1,407 写实＋1,320 动漫）。不含需单独授权的自建素材。
- AI Library：1,407 条写实来源映射，与上述写实库存重叠；按原始编号合并，保留双来源绑定。
- Fashionpedia：46 类服装／部件＋294 项属性，作为可选服装细化条件。
- 中文关键词搜索支持常见衣物与颜色，可同时筛选来源、服装类型、分类。选择结果进入正文、角色一致性提示词和导出文件。
- `data/bound-libraries.json`：可读取的完整绑定快照；同内容 JS 版本支持本地双击使用。
- `data/library-manifest.json`：上游固定版本、路径、日期、输入摘要和去重统计。
- `npm run sync:libraries`：从清单中固定的 GitHub 版本重新同步元数据，不下载图片；日后升级需先更新固定 commit 并复核 schema 与许可。生成页面本身不需要联网拉索引。
- 来源与许可见 [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md)。本次“库上 GitHub”指元数据、索引、绑定和同步代码，不包含受限图片整库。

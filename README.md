# 角色工坊

一个含静态基础版和 Lovart 本机完整版的中文角色工作台。基础功能无需密钥。选择身份、外貌、服装方向、性格和世界背景，组合生成可保存、复制和导出的虚拟人角色设定，覆盖虚拟博主、小说、游戏场景。

## 本机完整版

需要 Node.js 18+、Python 3.9+，不需要安装 npm 或 Python 依赖。

```sh
npm start
```

打开 http://localhost:4173/ 。无需 Lovart AK/SK 即可使用基础设定、个人参考库与「导出到 Lovart」。点击顶部「AI 模型接入」可在本机配置兼容文字／识图模型；Lovart 继续通过复制指令、手动上传参考图与发送完成创作。

已有可用 Lovart AK/SK 的账号仍可选用旧 API 流程：复制 `.env.example` 为 `.env.local`，仅用本机编辑器填写，修改后重启服务。没有凭据时无需配置，也不要将凭据提交到 GitHub。

- 旧 API 流程可设置 `LOVART_PROJECT_ID` 复用已有项目；未设置时，在网页的「服务与启动说明」中点击「创建专用 Lovart 项目」。不会自动创建项目或切换账户计费模式。
- 「捏脸与 AI」提供 13 组可输入、选择和锁定的面部与发型特征。基础设定在浏览器组合；AI 操作必须主动点击。
- 人物、服装、风格分别上传，单图不超过 10 MB，支持 PNG/JPEG/WebP。上传先存本机；点击提取、设计或预览才发送本次选中的参考至 Lovart。
- 图库与上传图并存时，通过「本次人物来源／服装来源」选择实际采用项；筛选不会清掉选择。
- 提取结果逐项勾选确认后才进入草稿。锁定值保留；手动值冲突会展示差异，需明确采用建议才能替换。保留原貌与原创重设计可切换。
- AI 设定需要点击采用；预览默认一张。预览保存在新版本，可与原始参考、上一版图片比较，满意后设为后续身份参考。文字锁定不能保证生图完全一致。
- 页面显示排队、处理中、待确认、超时或失败。恢复查询只查询原会话，不重新生成；服务重启也不会自动重发。Lovart Agent 可能自行选择其他工具，异常和拒绝结果不会假装成功。
- 角色草稿与档案在当前浏览器；最近 50 个生成版本自动记录，手动保存的档案长期保留。JSON v2 包含条件、锁定、提示词、版本和本机图片标识，兼容旧 v1。JSON 不包含图片文件和密钥；换电脑需另备份本机数据或重新上传。
- 私人图片、任务和项目编号在 `.local-data/`；配置在 `.env.local`，均忽略 Git 且不进入 `dist/`。后端只监听 127.0.0.1，同源网页调用，不提供公网访问。按 Ctrl+C 停止。

GitHub Pages 继续运行基础功能与参数捏脸，上传、AI 识图和预览只在本机完整版可用。在线旧档案可在「我的档案」导出，再在本机导入。

端口被占用时：`npm run build` 后运行 `python3 studio_server.py --port 4175`，访问相应端口。纯静态开发使用 `npm run start:static`（4174）。

Lovart 客户端固定上游版本，见 `vendor/lovart/UPSTREAM.json`；无需 Codex 技能目录。上游技能声明 MIT，许可证与来源随客户端保存。不会把第三方图库整库下载或发至 Lovart。

## 基础版使用

界面采用「角色样本工作室」：上方持续展示当前人物、服装和风格来源，左侧编辑条件，右侧查看生成版本。发型与整体服装方向在「外貌与造型」直接调整；图库、AI 模型接入、Lovart 导出、我的参考库各有独立弹窗。手机可用「编辑条件／查看档案」快速定位。未生成时显示空态，历史版本仍可从版本记录恢复。

直接打开 `index.html` 即可使用；也可执行 `npm run start:static`，访问 http://localhost:4174 。无需安装依赖。

1. 选择预设或修改角色条件。
2. 在「外貌与造型」选择发长和具体发型，可选关联原站参考记录。
3. 选择 1–3 项性格，补充语气与约束。
4. 生成设定，复制、下载 Markdown 或保存到「我的档案」。

修改条件会标明现有档案尚未更新；点击生成后使用新条件。预设和随机灵感只修改条件，不自动覆盖生成结果。

## 数据和边界

- **基础生成使用本地规则组合；AI 功能仅在本机完整版主动调用 Lovart。** 补充要求原样列入独立章节；不会对自由文本作语义推理。
- 姓名、习惯、弱点等细节随生成变化。相同条件可换一版，但不承诺每次全部段落不同。
- 人物参考来源： https://ai-portrait-gallery.pages.dev/ 。2026-11-13 提取 1,499 条公开记录（893 面部、606 造型）；四种发长与50种非空发型标签。中文为本项目编辑翻译。
- 只保存元数据与链接，不存储或代理原站图片。外观记录不用于推断年龄、性格、国籍等人物信息。
- 「参考资源」区分已绑定的服装元数据与其他调研候选，未导入图片，不代表已获素材再分发许可。见 [来源信息](docs/来源信息.md) 和 [GitHub资源调研](docs/GitHub资源调研.md)。
- 条件草稿与保存档案留在当前浏览器，不上传、不跨设备同步。可导出/导入 JSON 备份；清除浏览器数据会删除本机档案。保存失败会提示下载备份。

## 验证与构建

npm run build

`dist/` 只包含网页运行文件，不含开发文档、设计契约或凭据。所有资源使用相对路径，适配 GitHub Pages 项目子路径。

项目上下文与设计文档应一同提交：PRODUCT.md、DESIGN.md、.impeccable/surfaces/ 与 .impeccable/design.json。浏览器测试证据保留在本机 .impeccable/review/，不随站点发布。

## 三项库绑定

已经绑定 **Open Pose & Costume、AI Library、Fashionpedia**，在「外貌与造型」展开服装库选择。

- Open Pose & Costume：2,727 条上游服装元数据（1,407 写实＋1,320 动漫）。不含需单独授权的自建素材。
- AI Library：1,407 条写实来源映射，与上述写实库存重叠；按原始编号合并，保留双来源绑定。
- Fashionpedia：46 类服装／部件＋294 项属性，作为可选服装细化条件。
- 中文关键词搜索支持常见衣物与颜色，可同时筛选来源、服装类型、分类。选择结果进入正文、角色一致性提示词和导出文件。
- `data/bound-libraries.json`：可读取的完整绑定快照；同内容 JS 版本支持本地双击使用。
- `data/library-manifest.json`：上游固定版本、路径、日期、输入摘要和去重统计。
- `npm run sync:libraries`：从清单中固定的 GitHub 版本重新同步元数据，不下载图片；日后升级需先更新固定 commit 并复核 schema 与许可。生成页面本身不需要联网拉索引。
- 来源与许可见 [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md)。本次“库上 GitHub”指元数据、索引、绑定和同步代码，不包含受限图片整库。

## 看图筛选与选择

「外貌与造型」现提供人物／服装图库切换，每页 6 张图片，可按发长、参考类型、来源、服装分类及关键词筛选。点击图片单选，或点击「放大查看」检查大图；按 Escape 关闭。筛选与翻页不清除已选项，已选预览可随时取消。

人物选择会同步发长和具体发型，手动修改发型会取消人物参考，以避免相互冲突。生成后的角色档案包含人物／服装两张参考缩略图，固定相应编号及原图来源；服装正文使用所选条目的关键词，替代通用方向中的默认服饰。保存、恢复与 Markdown 导出都保留这些选择。

缩略图只在用户打开相应图库并滚动到附近时从原站加载，大图只在明确点击放大时读取。图片不会写入仓库、代理或离线缓存；失败时提供重试与原站链接。生成仍使用标签和本地规则，不运行视觉识别、换脸或生图。

可选浏览器验证：安装 Playwright 后，先 `npm start`，再设置 `SITE_URL=http://localhost:4173/` 运行 `node tests/gallery-flow.cjs`。也可用 PLAYWRIGHT_PATH、CHROME_PATH 指定测试环境。包含真实缩略图加载、选择与筛选保留、大图、错误重试、角色输出、导出、保存恢复与响应式检查。

## 分类式选图

人物图库支持「参考内容 → 发长 → 发型特征」分类；服装图库支持「画面类型 → 季节／场合 → 单品类型」分类。点击分类按钮组合条件后，再从匹配图片中选择参考。每组可选一项，不同组取交集；按钮数字是在其他当前条件下的匹配数，单套服装可归入多种单品类别，数字不宜相加。

发型特征与单品分类仅依据原站标签。其他或未标注发型特征的记录放在「其他 / 未标注」，未匹配单品关键词的记录放在「其他单品」，不按图片推断年龄、性别或人物性格。搜索、下拉控件与可见分类按钮同步；零结果有清空筛选入口。筛选、清空筛选及翻页都保留已选参考，不会代替你选择新图片。

分类规则位于 `reference-categories.js`。`tests/categories.test.cjs` 核对真实库存覆盖、混合单品和关键词边界；`tests/categories-flow.cjs` 检查组合筛选、联动数量、选中保留、生成引用、下拉同步、空结果恢复与响应式布局。

## 升级验收

`npm test` 验证规则、分类、锁定、来源和版本；`npm run test:server` 使用假客户端验证上传限制、重复请求、异常文字、参考拒绝、无图片、超时恢复、确认与重启，不调用付费服务。

启动本机版后，设置 `PLAYWRIGHT_PATH` 为 Playwright 安装目录、`SITE_URL=http://localhost:4173/`，运行 `node tests/studio-flow.cjs`。该浏览器测试真实调用本机上传，拦截所有 Lovart 任务响应，不消耗额度。原有 `gallery-flow.cjs` 和 `categories-flow.cjs` 继续回归图库。真实 Lovart 生成验收由用户配置后在网页点击触发。

## 导出到 Lovart（无需 AK/SK）

点击页头「导出到 Lovart」，选择「角色设定＋一张预览图」「只整理设定与提示词」或「只识图提取特征」。导出实时使用当前表单的参数、锁定、来源和改进要求，不使用尚未更新的旧档案。可填写已有 Lovart 项目链接，留空打开首页；仅接受 Lovart HTTPS 首页／canvas 项目链接。

点击「复制并打开 Lovart」后，在 Lovart 粘贴指令，上传／关联清单中的参考图，再亲自发送。可仅复制或下载 Markdown 备份。第三方图库只输出当前有效参考的链接，不批量下载图片。本机上传图不会随文本导出传输；图片文件必须另行上传。网页不自动提交生成、不读取 Lovart 的登录凭据、不自动同步结果，也不把本地文件地址当作 Lovart 可访问的图片链接。API 接入保留为已有可用凭据账号的可选功能，当前推荐使用半自动导出。

## AI 模型接入

顶部「AI 模型接入」打开配置区。本机版可填写 OpenAI 兼容 Chat Completions 的 Base URL、文字模型 ID、可选识图模型 ID 与 API Key，保存后立即用于文字／识图任务，无需重启。云服务要求 HTTPS；localhost／127.0.0.1 的本地兼容服务可用 HTTP，无鉴权时密钥可留空。模型名、区域地址与账号权限以服务控制台为准。

配置仅保存在本机 `.local-data/ai-config.json`，权限 0600；读取接口只返回密钥是否存在，不返回密钥。留空保留同域名已有密钥；更换服务域名需重新填写密钥。支持清除配置，档案和 Lovart 导出不含接入配置。测试已保存连接会发一次短文本请求，可能收费；测试成功只表示文字调用有效，识图需单独验证。

启用兼容配置后，AI 设定走文字模型；涉及选中参考图的设定或提取需配置识图模型，上传图以图片内容发送，不使用不可访问的本机 URL。兼容接口本次仅接文字与识图，生图继续通过 Lovart 导出；已有 Lovart API 接入保留。在线 Pages 版只展示说明，不收集密钥或在浏览器直接调用模型。新后端部署后需重启现有本机服务一次。

接口依据：[DeepSeek](https://api-docs.deepseek.com/)、[百炼兼容接口](https://help.aliyun.com/zh/model-studio/compatibility-of-openai-with-dashscope)、[Chat Completions](https://developers.openai.com/api/reference/resources/chat)。

## 三个独立弹窗入口

顶部「看图选择人物与服装」「AI 模型接入」「导出到 Lovart」分别打开独立弹窗。支持关闭按钮、Esc、点击遮罩，关闭后焦点返回入口；本页内的筛选、选择、任务类型、目标项目和未保存的配置输入保持不变。刷新会丢弃未保存的配置输入，密钥保存方式不变。弹窗内部滚动，手机端保持关闭区可见。图片放大是图库内的第二层弹窗，Esc 先关闭图片。

图库默认折叠高级分类筛选，让可选图先出现；展开后仍可组合分类并查看联动数量，搜索与当前筛选路径保持可见。图库选择仍属角色条件表单，生成与导出使用相同参数。校验失败时关闭弹窗并显示需要修改的字段。关闭弹窗不会取消已经提交的模型任务。

## 我的参考库

顶部「我的参考库」打开独立弹窗。可先建立小红书收藏夹、Behance Moodboard、Pinterest 看板或本地素材分组，链接和图片以后再添加。来源链接仅记录与跳转，不自动抓取、登录或同步收藏夹。选定分组后可批量导入 JPG/PNG/WebP（每张最多 10 MB），通过名称搜索，选择人物提炼对象、服装或风格用途。

选择图片后进入现有角色条件；本机版会将所选图片保存到本机参考图服务，再由用户主动点击识图提取。在线版可用于基础设定和 Lovart 导出，图片需要在 Lovart 另外上传。参考库图片和分组保存在当前浏览器 IndexedDB，不写入 GitHub，不随角色 JSON 备份携带图片；请保留原始图片。清除浏览数据会删除该浏览器的参考库，不跨设备自动同步。
